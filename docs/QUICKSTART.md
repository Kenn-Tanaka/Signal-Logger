# クイックスタートガイド

対象：初めてData-Loggerを使う利用者。詳細は[リファレンスマニュアル](REFERENCE_MANUAL.md)、動作条件は[README](../README.md)を参照してください。

## 1. 準備

1. Windowsで入力デバイスを認識させ、必要なドライバを用意します。
2. 入力機器の許容範囲内の信号を接続します。フルスケール電圧の設定では過電圧を防止できません。
3. 保存先の空き容量を確認します。まず重要でない信号で短時間試してください。
4. `DataLogger.exe` を起動します。

AC結合の機器では直流成分は保持されません。低い記録レートを選ぶだけでDC計測に対応するわけではありません。

## 2. 保存せず波形を確認する

1. 「ライブ入力」で入力デバイスとチャネル数を選びます。
2. 「入力レート」を選びます。32kHzは対応照会に通った場合だけ候補になります。
3. デシメーションを選び、表示された実際の記録レートを確認します。
4. 「プレビュー開始」を押します。この段階では保存されません。
5. 時間幅、垂直ゲイン、波形ホールドで表示を調整します。ホールドは取得停止ではありません。

機器設定を変更できないときは、先にプレビューを停止してください。

## 3. 記録する

1. 必要ならチャネル名・単位、フルスケール電圧を設定します。単位名変更だけでは物理量の換算は行われません。校正を行う場合は「校正...」を押します。プレビュー中または停止中（停止時は自動でプレビュー開始を確認）に対話型ダイアログが開き、直近の信号統計（実測Vpp・ピーク・クリッピング判定）をリアルタイムに確認しながら安全に適用できます（記録中は換算係数の変更はできません）。
2. 「保存先」に新しい `.bin` または `.dat` のパスを指定します。
3. 「記録開始」を押します。既存ファイルへの上書き確認には注意してください。
4. 記録中の欠落回数と保存状態を確認します。UI描画スキップは記録欠落とは別です。
5. 停止ボタンで記録を終了し、保存完了またはエラーを確認します。
6. 完成したDLOGと `ファイル名.bin.meta` を一緒に保管します。

停止後はプレビューへ戻る場合があります。「波形が動いている」ことだけで保存中と判断しないでください。重要な計測では欠落回数・保存先・エラーを別途記録してください。メニュー「言語 / Language」により記録中・変換中を問わずいつでも日本語／英語を切り替えられます（言語切替によって保存形式や設定が変更されることはありません）。

## 4. 保存済みデータを表示する

1. 記録・プレビューを停止し、「記録データ再生」へ切り替えます。
2. ファイルを開きます。記録中の `.partial` は通常の再生対象ではありません。
3. 時刻欄に秒数（例：`12.5`）または `00:00:12.500` を入力して移動します。
4. 再生／一時停止、先頭、末尾、スライダーを使用します。
5. 再生速度を選択します。倍率は画面上の時刻の進み方を変え、保存データは変更しません。

表示が遅れる場合は一時停止し、時間幅を短くして位置を指定してください。

## 5. CSV／TSVへ変換する

1. `DlogToCsv.exe` を起動します。
2. 「ファイル追加...」またはドラッグ＆ドロップでDLOGを登録します。
3. 保存先、時間列、出力チャネル、区切り、数値精度を選びます。
4. 必要なら時間範囲と行分割を設定します。初回は100万データ行の分割を使用できます。
5. 「変換開始」を押し、各ファイルの完了／エラーを確認します。
6. 出力先を開いて内容を確認します。

再実行では既存出力を上書きします。元のCSVが必要なら先に別フォルダへ退避してください。変換時の間引きは、記録時のLPF付きデシメーションとは異なります。

## 6. 異常終了した場合

1. 記録プロセスを停止し、`.partial` の原本を別媒体へコピーします。
2. コンバータの「不完全ファイル復旧...」から停止済みファイルを選びます。
3. 復旧先が一覧に追加されたら、記録時間・波形・チャネル名を確認します。
4. 検証が済むまで原本を削除しないでください。

復旧は残っている完全フレームのコピーです。未書込データや取りこぼした区間は復元できません。詳しくは[障害対応](REFERENCE_MANUAL.md#障害対応)を参照してください。
