# リファレンスマニュアル

対象：DataLogger、DlogToCsv、補助Pythonツールの利用者。実装仕様書と開発規約はバイナリ配布には含みません。ソース・ビルダー配布を参照してください。補助Pythonツールもビルダー配布に含まれます。

## 用語と測定上の注意

- **入力レート**：PortAudioへ要求する毎秒フレーム数。1フレームには全チャネル各1サンプルを含みます。
- **記録レート**：入力レートを整数Nで割った値。
- **プレビュー**：取得と表示のみ。DLOGへ保存しません。
- **記録**：取得データのファイル保存を指します。
- **再生**：保存済みデータのグラフ表示。スピーカー出力はありません。
- **欠落回数**：検出イベント数。失われたサンプル数や欠落時間そのものではありません。
- **フルスケール電圧**：正規化PCMの±1.0に対応する電圧。ハードウェアの入力レンジを変更する機能ではありません。

入力機器の結合方式と許容入力を確認してください。AC結合によるDC遮断をソフトウェアでは取り消せません。単位ラベルをAやkPaにしても、センサー感度・オフセットを自動適用する機能にはなりません。

## ライブ入力の設定

| 項目 | 操作・意味 |
|---|---|
| 入力デバイス／更新 | 接続済み入力を列挙。切断後は停止してから更新 |
| チャネル数 | デバイス上限かつ最大8ch |
| チャネル設定 | 名称・単位を波形と付随メタデータに使用 |
| 入力レート | 32、44.1、48、88.2、96、192kHzのうち形式照会が成功した候補 |
| デシメーション | 1/1、1/2、1/4、1/8、約1000／100／10／1Hz |
| アンチエイリアス | チェックONでFIR／移動平均LPFを適用。OFFで単純間引き（1/1選択時は無効化） |
| フルスケール電圧 | 正の値。表示・変換のスケーリングに使用 |
| 保存先 | DLOGの最終名。一時ファイルは同じフォルダに作成 |
| プレビュー開始／停止 | 保存なしの取得を開始・停止 |
| 記録開始／停止 | ファイル保存を開始・終了 |

形式照会はデバイス・チャネル数・API・Float32の組合せに対する結果です。OS／ドライバ内部のレート変換を排除する保証ではありません。候補にないレートの手入力はありません。

約1000Hzなどは整数Nへ丸めます。44.1kHzでは1/44で約1002.272727Hz、32kHzでは1/32で1000Hzです。厳密な1000Hzへの有理数変換は行いません。

アンチエイリアスチェックボックスは、デシメーション時のローパスフィルタ（$N \le 8$ では17タップFIR、$N > 8$ ではボックスカー平均）を有効にします。パルスやステップ応答のフィルタ遅延・リンギング（ギブズ現象）を排除したい場合や、瞬時値の単純間引きを行いたい場合はチェックを外します。ネイティブ（1/1）選択時は間引きが発生しないため自動的に無効化（グレーアウト）されます。記録結果の付随メタデータ（`.meta`）には `anti_aliasing=true` または `false` として記録されます。

### 校正

1. 許容入力内の既知の交流信号をCH1へ入力し、プレビューで安定した波形を表示します。
2. 波形ホールドを解除し、クリップしていないことを確認します。
3. 「校正...」で既知の振幅をVpp（最大値－最小値）として指定します。
4. CH1の直近1秒のデジタルVppから共通フルスケール電圧を計算します。
5. 校正後は、機器の入力ゲイン変更で換算が変わるため再確認します。

校正操作（「校正...」ボタンおよびフルスケール電圧の直接入力）は、プレビュー中または停止中にのみ実行可能です。記録中は換算係数の不整合を防ぐため厳格に無効化されます。RMS値や片振幅をVppとして入力しないでください。これはCHごとの独立校正や周波数応答の補正ではありません。

## 波形表示・時間軸

時間幅は1、2、5、10、20、50、100、200、500ms、1、2、5、10sです。横軸は10分割で、1divは表示時間幅の1/10です。例えば2ms幅なら200μs/divです。

目盛は画面中心を0とした相対値で、別表示の「中心時刻」と組み合わせます。記録開始を0秒とする時刻と、画面中心相対の0を混同しないでください。プレビュー中はプレビュー開始が基準です。

垂直ゲインは表示倍率です。保存PCMや入力機器のゲインは変更しません。ピーク・電圧・dB・クリップ表示は画面確認用で、校正証明や精密なRMS測定の代用ではありません。

波形ホールド中も記録は継続します。再生では一時停止を使います。長い時間幅・多チャネルでは表示計算が重くなることがあります。

## 記録・保存

保存中は隣接する `.partial`（衝突時は枝番）を使用し、停止後に最終名へ確定します。DLOGとその `.meta` はセットで移動・保管してください。

画面の記録欠落はPortAudio入力オーバーフロー、Rawキュー溢れ、保存キュー溢れを集計します。UI描画スキップは別カウンタです。欠落0でも外部機器や物理信号の異常がないことまでは保証しません。

必要容量の概算は `4 × チャネル数 × 記録レート × 秒数 + 64` バイトです。192kHz・8ch・1時間・間引きなしなら約22.1GB（10進）です。余裕を持った空き容量を確保してください。

停止時にキュー排出・フラッシュ・確定を待つ場合があります。強制終了しないでください。スリープ抑制は停電、強制シャットダウン、すべての電源操作を防ぐものではありません。

## 記録データ再生

- ファイルを開き、先頭／末尾、スライダー、時刻指定で移動します。
- 秒数、MM:SS、HH:MM:SSと小数秒を指定できます。位置はサンプル境界へ合わせます。
- 最終サンプル位置は `(総フレーム数−1)/記録レート`。記録長 `総フレーム数/記録レート` とは1サンプル分異なります。
- 倍率：0.25、0.5、1、2、4、8、16倍。原本は編集しません。
- 時間窓が記録の外へはみ出す部分にはデータがありません。
- 高倍率・低速ストレージでの滑らかさは保証されません。正確な位置確認には一時停止を使用します。
- ファイルの編集、切取り保存、Undo／Redo、音声出力はありません。

## CSV／TSV変換

| 設定 | 内容 |
|---|---|
| 入力登録 | ファイル追加、フォルダ追加、ドラッグ＆ドロップ |
| 選択削除／全クリア | 変換一覧から除外する操作。原本の削除ではない |
| 保存先 | 入力と同じフォルダ、または指定フォルダ |
| 時間列 | 相対秒、UTC絶対日時、サンプル番号、なし |
| 間引き | 1/1、1/2、1/4、1/5、1/10、1/20、1/50、1/100 |
| 区切り | カンマなら.csv、タブなら.tsv |
| 数値精度 | 小数点以下4、6、8桁。元データの有効精度は増えない |
| 電圧換算 | PCMにフルスケール電圧を掛ける。無効時は正規化PCM |
| チャネル | 全チャネルまたは指定チャネル。名称・単位の上書き設定あり |
| 時間範囲 | 開始秒・終了秒。終了0は末尾まで |
| 行分割 | 指定データ行数ごと。各出力にヘッダ行を追加 |
| 中断 | 処理の中断を要求。完了済み出力は残る |

CSV側の間引きはサンプル選択であり、追加のアンチエイリアスフィルタはありません。時間列は元記録のフレーム位置が基準で、切出し開始を自動的に0秒にはしません。相対秒は小数6桁、絶対日時はミリ秒表記のため、高レートでは同じ表示時刻が並ぶ場合があります。

分割名は `name-01.csv` 等で、総分割数に合わせて桁数が増えます。分割不要なら `name.csv` です。同名の再変換は上書き既定です。分割条件を変更した再変換では、以前の余分な分割ファイルが残る可能性があるため、新しい空フォルダを推奨します。

出力計画に基づく衝突検査がありますが、複数プロセスから同じ出力先を同時に使用しないでください。キャンセルはバッチ全体のロールバックではありません。

## 障害対応

| 症状 | 確認・対応 |
|---|---|
| 起動しない | EXEの場所、エラー、OS、配布版を記録。必要なら `--smoke-test` の終了コードを確認 |
| 入力デバイスがない | 接続、ドライバ、Windows側の入力許可、有効な入力を確認して一覧更新 |
| 入力レート候補が空 | チャネル数・デバイスを変更。他アプリの占有も確認 |
| DCが表示されない | 機器の結合方式・周波数特性を確認。レート変更だけでは解決しない |
| クリップ | ハードウェア側の入力を下げる。表示ゲイン低下ではクリップを解消できない |
| 欠落増加 | 記録条件と保存先を見直し、欠落がある測定として記録する |
| ディスク／確定エラー | 表示された回収先と原本を保全。空き容量・権限を確認 |
| 再生が遅い | 一時停止、短い時間幅、ローカルコピーで確認 |
| 名称・単位が不正 | 本体と.metaの組合せを確認。既定CH名へ戻る場合もある |

### 不完全ファイルの復旧

コンバータの「不完全ファイル復旧 (.partial)...」は、完全フレーム部分を別ファイルへコピーし、成功したファイルを一覧へ追加します。原本は保持します。既存の最終名があれば回収名に枝番を使用します。

記録中のファイルには実行しないでください。まず原本をバックアップしてください。出力先にコピー分の空き容量が必要です。末尾の不完全フレームは回収対象外で、過去の欠落・未書込データ・失われたメタデータは復元できません。復旧後のReader検査と内容確認が必要です。

## Python補助ツール

Python 3とNumPyが必要です。必要ならプロジェクト専用仮想環境へ導入してください。

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install numpy
.\.venv\Scripts\python tools/read_dlog.py recording.bin --info
.\.venv\Scripts\python tools/read_dlog.py recording.bin --wav output.wav
```

情報表示とWAV変換のみで、波形プロット機能はありません。WAVは16-bit PCMへ量子化され、非整数の記録レートは整数に丸められます。精密解析の原本はDLOGを使用してください。WAVの既存出力は上書きされます。

## 設定・終了・保管

設定の永続保存を前提にせず、毎回デバイス、レート、電圧、保存先を確認してください。終了前に記録と変換を停止します。ポータブル運用では実行ファイル・ライセンス通知・文書をセットで保管し、測定データは別途バックアップしてください。

## 言語設定とデータ形式の独立性

- メニュー「言語 / Language」による表示言語（日本語／English）の切り替えは、UI表示のみに反映され、保存されるDLOGバイナリ形式、付随メタデータ（`.meta`）、およびCSV/TSV出力の数値表現・区切り文字・浮動小数点フォーマットを変更しません。
- 同一のDLOG入力ファイルに対するCSV変換結果は、日本語環境と英語環境の間で100%バイト一致（完全一致）することが保証されています。
- ただし、実機ハードウェアを用いて別個に実施された2回の独立した計測セッションは、サンプリングクロックやOSスケジューリングの微小な物理的タイミング差により、言語設定の如何にかかわらずビット完全一致することは保証されません。
